# Fictional Student Dataset

This project contains a fictional dataset created with Python for the CUL-CYB 371 Data Mining and Data Warehousing assignment.

## Dataset fields
- Student_ID
- Department
- Level
- Attendance_Percentage
- Average_Examination_Score

## Files
- `create_dataset.py`: Python program that creates the dataset.
- `students.csv`: Dataset containing 15 fictional student records.

## How to run
1. Install Python 3 if it is not already installed.
2. Open a terminal in this project folder.
3. Run: `python create_dataset.py`
4. The program creates `students.csv` in the same folder.

All student records are fictional and are for academic demonstration only.
